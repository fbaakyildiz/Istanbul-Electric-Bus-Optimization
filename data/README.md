# Data

Raw operational data is not included.

The notebooks expect local input files from the senior design project, including:

- IETT route and stop datasets
- hourly and seasonal passenger boarding datasets
- route distance and slope files
- simulation summary output spreadsheets

Suggested local structure:

```text
data/
├── raw/
├── processed/
└── outputs/
```

Do not commit private operational datasets or API credentials.
